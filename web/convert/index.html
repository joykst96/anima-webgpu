Anima 체크포인트 변환

Anima 2B(28블록) 계열 DiT .safetensors를 이 브라우저에서 생성 페이지용 ONNX(int8)로 바꿉니다. 파일은 서버로 올라가지 않습니다. 결과는 ComfyUI 변환 파이프라인과 같은 바이트입니다.

생성 페이지에서 쓰기

모델 → 사용자 설정 (직접 모델 지정) → DiT 모델 파일에서 결과 폴더(…_base 또는 …_turbo) 안의 파일을 전부 선택한 뒤 모델 로드. LoRA·'빠르게' 모드도 서버 모델과 똑같이 동작합니다. 크기는 변형당 2.3GB(Turbo 포함 4.6GB).
