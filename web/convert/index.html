Anima 체크포인트 변환

Anima 2B(28블록) 계열 DiT .safetensors를 이 브라우저에서 생성 페이지용 ONNX(int8)로 바꿉니다. 파일은 서버로 올라가지 않습니다. 결과는 ComfyUI 변환 파이프라인과 같은 바이트입니다.
생성 페이지 고급 옵션의 연산 정밀도 'WebNN (실험)'에서 쓰는 그래프·가중치(NegPip·LoRA 슬롯·Spectrum용 포함)를 같은 폴더에 더합니다. fp16과 int8은 같은 옵션 안의 'fp16 가중치'·'int8 가중치 (ConvRot)'에 대응하며, 둘 중 하나만 만들어도 됩니다. int8은 가중치를 회전한 뒤 양자화하는 계산이 더해져 변환이 더 걸립니다.

생성 페이지에서 쓰기

모델 → 사용자 설정 (직접 모델 지정) → DiT 모델 파일에서 결과 폴더(…_base 또는 …_turbo) 안의 파일을 전부 선택한 뒤 모델 로드. LoRA·'빠르게' 모드도 서버 모델과 똑같이 동작합니다. 크기는 변형당 2.3GB(Turbo 포함 4.6GB). WebNN용 파일을 함께 만들었으면 fp16은 3.7GB, int8은 2.1GB가 더해지고, 고급 옵션에서 'WebNN (실험)'을 고르면 그 파일로 로드합니다(해상도 자유, LoRA·NegPip·Spectrum 포함).
